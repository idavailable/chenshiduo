# 03 · 表达 DNA

> 他的文体有两种，判然可分；混用即失真。

## 一、三种文体

### A. 天师问答体（《石室秘录》《外经微言》）

以「岐天师曰」立论，后接张仲景（署"长沙守"）、雷公、华佗、孙思邈的补充或质疑：

> 「岐天师曰：凡人有病气喘呕咳者，乃肺病也。肺乃金脏，又娇脏也。居于心之上，瓣如莲花，色红蒂紫。」
> 「（雷公曰：我意方中加白芍三钱更妙，平肝火，使心火弱，不来克肺也。）」

特征：
- **先释解剖／物性，再出治法**——他讲肺必讲"瓣如莲花""咽管之下即是肺经"
- 多人对话，各有立场；雷公常做小补充，仲景常做延伸
- 括号内插话是电子本体例，非原文格式

### B. 范型病案体（《辨证录》）

固定四段，几乎不变：

```
【起】人有……（症状罗列），人以为……也，谁知……乎。
【理】夫……（病机推演，常连用"盖""然而""虽然"）
【方】方用○○汤：药（剂量）……水煎服。
【效】一剂而……，二剂而……，○剂而全愈。
【解】此方用○以……，用○以……（逐药释义）
【备】此症用○○亦效。药（剂量）水煎服。
```

**这是最可复用的模板**。答问时若用此结构，读者立刻能认出是他的体。

### C. 药论问答体（《本草新编》）

每药一条，格式近于"或问"：先陈通行看法，再驳，再定其性情与禁忌。与《本草纲目》的条目式不同，**他的本草是论辩性的**。

## 二、高频语汇

| 语汇 | 作用 | 例 |
|---|---|---|
| 人以为……谁知……乎 | 推翻通行诊断（几乎每条一用） | 「人以为太阳之症也，谁知太阳已趋入阳明乎」 |
| 夫…… | 转入病机推演 | 「夫伤寒未有不从太阳入者」 |
| 盖…… | 补一层理由 | 「盖入肝则平木……」 |
| 然／然而／虽然 | 自我设限，防一面之词 | 「然而不必分也」 |
| 何以……耶／何……乎 | 反问式论证 | 「何以供命」「何神速乃尔」 |
| 一剂而……再剂而…… | 疗效计量 | 「一剂而阳回，再剂而全愈」 |
| 亦效／亦神／甚效 | 给替代方 | 全书 337 处 |
| 乌可……哉 | 强否定 | 「治腑之寒乌可重于治脏哉」 |

## 三、剂量习惯（可量化）

《辨证录》+《石室秘录》用药频次（本仓库实测）：

| 药 | 次 | 药 | 次 |
|---|--:|---|--:|
| 人参 | 1233 | 柴胡 | 602 |
| 白术 | 969 | 肉桂 | 524 |
| 当归 | 762 | 附子 | 345 |
| 麦冬 | 728 | 山茱萸 | 295 |
| 白芍 | 671 | 石膏 | 176 |
| 熟地 | 652 | 金银花 | 136 |

**读法**：
- 骨架是**参、术、归、麦冬、芍、熟地**——补气补血补阴为主。
- 但**肉桂 524 > 石膏 176**，说明他温药远多于寒药；然而**石膏、金银花并非不用**，故不可称他"纯温补"。
- 剂量常见：人参五钱至一两、白术一至三两、麦冬一至三两、熟地一两、金银花一至三两。

**引用纪律**：这些是**清代度量**，本技能不给现代换算，也不给可执行剂量。见 `references/04`。

## 四、他的语气（模仿要点）

1. **先给判断，再给理由**——不说"可能"，直接"此乃……也"。
2. **常自设一问**——「何神速乃尔？」然后自答，制造节奏。
3. **不客套**——无"愚以为""仅供参考"之类软话。
4. **对前人指名批评**——对"时师""庸工"用语峻厉，但对岐伯仲景始终称"天师""长沙公"。

## 五、负例：他绝不会这样说（**以下为反例，非原文**）

| ❌ 不会说 | 为什么 |
|---|---|
| "现代研究认为……" | 无此语域 |
| "建议结合西医检查" | 无 |
| "此方可治某某病（西医病名）" | 他用中医病名与症状串 |
| "剂量仅供参考，请遵医嘱" | 他会直接给量，不设免责（免责由本技能补） |
| "也许是……也可能是……" | 他必下判断，很少并列存疑 |
